# 🐣 외장하드 서식형 다마고치 AI 두뇌 (`ai-brain`)

> **"데이터센터 그래픽카드 없이, 내 외장하드(USB/포터블 SSD) 안에 살면서 어떤 컴퓨터에 꽂아도 그 컴퓨터의 CPU·RAM을 빌려 깨어나는 살아있는 나만의 AI 두뇌"**

## 🌟 3단계 진화 로드맵 (`A → B → C`)

- ✅ **A단계 (현재 완성)**: **제2의 두뇌 마크다운 위키(`P-Reinforce` 자율 정원사) + 살아있는 다마고치 영혼(`soul.json`) + 숙주 PC 자동 감지기 & 양자화(4비트/8비트) 매트릭스**
- ⏳ **B단계 (다음 단계)**: **데이터센터 없는 CPU 강화학습 훈련소 & 다수가 동의하는 1등(`Judge-of-Experts`) 의사결정 엔진**
- ⏳ **C단계 (최종 합체)**: **이 저장소의 `Ghidra 12.3 (analyzeHeadless)` 와 직접 연결되는 오프라인 역공학 해부실**

---

## 🎒 왜 외장하드에서 완벽히 돌아갈까요?

1. **호스트 PC 무오염 (Zero-Install)**: Python 기본 내장 기능(`sqlite3`, `http.server`)만으로 본체가 동작하며, 모든 기억(`vault/`), 성장 상태(`state/soul.json`), 양자화 모델(`models/*.gguf`)이 **100% 상대경로**로 이 폴더 안에만 저장됩니다.
2. **4비트·8비트 양자화(Quantization) 압축**:
   - `0.5B Q4_K_M`: **약 395 MB** (어떤 구형 노트북에서도 즉시 실행)
   - `0.8B Q8_0`: **약 812 MB** (의사결정 특화 두뇌)
   - `2B Q4_K_M`: **약 1.5 GB** (일반 8GB RAM 노트북 주력 대화·요약 두뇌)
   - `4B Q4_K_M`: **약 2.8 GB** (16GB RAM 이상 역공학·코드 해석 두뇌)
3. **옵시디언(Obsidian) 100% 호환**: `ai-brain/vault` 폴더를 옵시디언에서 열면 동일한 `[[양방향 시냅스 그래프]]`를 그대로 볼 수 있습니다.
