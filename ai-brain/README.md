# 🧠 시냅스몽 · 외장하드 서식형 다마고치 AI 두뇌 (`ai-brain/`)

> **데이터센터 없이, 내 외장하드 안에서 자라나는 살아있는 나만의 양자화 AI 두뇌**  
> 외부 모델을 통째로 내려받아 빌려 쓰는 대신, **외부 모델의 골격 설계 원리만 해부해 참고하고 내 마크다운 위키 지식으로 직접 4비트·8비트 양자화 두뇌(`.sbrain`)를 주조**합니다.

---

## ✨ A단계 v2 핵심 구성

1. **8가지 감정·장면의 시냅스몽 & 작업 환경 상태창 (`web/assets/01~08`, `tamagotchi.py`, `host_probe.py`)**
   - 인사(`01_greet`), 호기심(`02_curious`), 소용돌이 흡수(`03_swirl`), 고민(`04_brainstorm`), 영감(`05_drop`), 별자리 연결(`06_star`), 유레카(`07_eureka`), 여정(`08_journey`) 8컷 캐릭터가 행동에 따라 살아 움직입니다.
   - `지식 포만감 · 기분 · 경험치` 바로 아래의 **작업 환경 상태창**이 현재 꽂힌 컴퓨터의 여유 RAM, CPU 코어, 외장하드 여유 공간과 주조 적합도 점수를 실시간 진단합니다.
2. **자율 마크다운 위키 정원사 (`wiki_gardener.py` + `vault/`)**
   - 메모나 분석 노트를 넣으면 YAML 메타데이터, 해시태그, 기존 기억과의 `[[양방향 시냅스 링크]]`를 자동 생성해 `.md` 파일로 영구 보존합니다.
3. **외부 모델 골격 해부대 & 독자 양자화 주조소 (`quant_forge.py` — `SynapseQuant`)**
   - **골격 해부대**: 외부 오픈모델(`Qwen 0.8B`, `Gemma 4 E2B`) 및 실제 `.gguf` 바이너리 헤더를 분해해 가져올 핵심 원리(GQA, SwiGLU, 블록 양자화)와 덜어낼 거대 다국어 군더더기를 분리합니다.
   - **직접 주조소**: 내 위키 어휘와 시냅스 공출현 행렬로 신경망 가중치를 학습한 뒤, **32개 단위 대칭 블록 스케일링(`FP16 scale`) + `INT4` 니블 패킹(1바이트에 4비트 가중치 2개 수납) / `INT8` 양자화**를 직접 수행하여 `models/*.sbrain` 파일을 생성하고 압축률(`~84% 절감`)과 코사인 정밀도를 계측합니다.

## 🚀 외장하드에서 바로 실행하기

- **Windows**: `start_windows.bat` 더블클릭
- **macOS / Linux**: `./start_mac_linux.sh` 실행
- **직접 실행**:
  ```bash
  python3 ai-brain/launch_brain.py --host 0.0.0.0 --port 8765
  ```

- **[완료] A단계**: 포터블 시냅스몽 본체 + 마크다운 위키 정원사 + 외부 골격 해부 및 자체 `INT4/INT8` 양자화 두뇌 주조소 + 환각 진단·처방실
- **[완료] B단계 (`rl_gym.py`)**: 데이터센터 GPU 없이 숙주 CPU만으로 수백~수천 판 훈련하는 **5인 꼬마 뉴런 강화학습 체육관** + 가중치 병합 없는 **다수 심판 합의(`Poor Voters, Good Judges`)** + **선택지 확률 채점 및 75% 미만 주인님 코칭(`Human-in-the-Loop`)** + `rl_council_int8.sbrain` 양자화 정책 저장
- **[완료] B+ 무한 성좌 & 천재 심사원 (`genius_pantheon.py`, `genius_scout.py`)**: 영역별 천재 성좌 원탁 담론, 주인님 생각 입체 피드백, 동서양 50+ 인물 업적·강점·한계 검증 및 자유 성좌 배치·이동
- **[완료] C단계 (`self_evolving_forge.py`, `ghidra_scripts/SynapseDissectHeadless.py`)**: **4대 핵심 능력 × 5대 필수 기관 × 6단계 자가 진화 시냅스 공방** — `Ghidra 12.3` 헤드리스 브리지 & Binary X-Ray 분해 → 핵심 원리 설계도 번역 → 우리 식 파이썬 코딩 → 원인 역추적 돋보기 & 복어 독 제거기 → 타임머신 세이브 & 투명 유리방 쌍둥이 검증 → `.py` + `.sbrain` + `[[위키 기억]]` 영구 스킬 카트리지 장착
- **[완료] D단계 (`evolution_heartbeat.py`)**: **자가 진화 심장박동 💓** — 주인님이 자리를 비운 사이 두뇌가 2분마다 스스로 꿈 조각(니블 팩커·패리티 수호기·델타 압축기·데드존 양자화기·다수결 스무더·체크섬 파수꾼 6종)을 6단계 공방으로 혼자 진화시켜 영구 장착하고, 장착 후에는 약화된 버그를 심어 면역력을 검증하는 **예방접종 훈련**으로 전환. 모든 과정은 「주인님 없는 사이의 진화 일지」 UI와 박동 알림 토스트로 실시간 보고
