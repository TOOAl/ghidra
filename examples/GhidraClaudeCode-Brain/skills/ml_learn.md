# ML 학습 — 3단계 (30줄)

10개 분석을 모아서 "C2 vs 취약점" 분류기를 로컬에서 학습. 다음 분석은 80% 자동 분류.

## 언제 발동

세션 10개 쌓이면 자동, 또는 "학습해줘" 트리거

## 3단계

1. **모으기**: `ml/learn.py`가 session 10개에서 특징 3개 추출 (C2키워드, 취약키워드, 도구 수).
2. **학습**: KNN 1줄로 학습, model.json 저장. sklearn 없이도 로컬 무료.
3. **예측**: `predict(task)`로 다음 분석 자동 분류. `hindsight`와 연결해 틀리면 재학습.

## 출력 규칙

*   보고서에 `학습: 10개 → 정확도 80% PASS` 1문장 필수

## 예시

> 학습: 10개 → 정확도 90% PASS, 다음 C2 분석은 자동 C2 분류
