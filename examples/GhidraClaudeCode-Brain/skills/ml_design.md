# ML 설계 — 3단계 (30줄)

"분석기 만들어줘" 한 마디면, 두뇌가 5개 블록으로 설계도를 그려.

## 언제 발동

"설계해줘", "구조 짜줘" 트리거 시

## 3단계

1. **분해**: `notion/design.py`가 요구사항에서 키워드 찾기. "분석" 있으면 분석기 템플릿(수집→디컴파일→탐지→보고서→저장소).
2. **그리기**: `create_block` 5번으로 블록 생성. 첫 블록이 부모, 나머지는 자식.
3. **검증**: `reasoning.py`로 설계 모순 0개 확인, `query_database`로 과거 설계와 비교.

## 출력 규칙

*   보고서에 `설계: 5블록 →` 목록 1개 필수

## 예시

> 설계: 수집기 → 디컴파일러 → 패턴탐지 → 보고서 → 저장소 (악성코드 분석기)
