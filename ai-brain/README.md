# 🧠 시냅스몽 · 외장하드 서식형 다마고치 AI 두뇌 (`ai-brain/`)

> **데이터센터 없이, 내 외장하드 안에서 자라나는 살아있는 나만의 양자화 AI 두뇌**  
> 외부 모델을 통째로 내려받아 빌려 쓰는 대신, **외부 모델의 골격 설계 원리만 해부해 참고하고 내 마크다운 위키 지식으로 직접 4비트·8비트 양자화 두뇌(`.sbrain`)를 주조**합니다.

---

## ✨ A단계 v2 핵심 구성

1. **8가지 감정·장면의 시냅스몽 & 작업 환경 상태창 (`web/assets/01~08`, `tamagotchi.py`, `host_probe.py`)**
   - 인사(`01_greet`), 호기심(`02_curious`), 소용돌이 흡수(`03_swirl`), 고민(`04_brainstorm`), 영감(`05_drop`), 별자리 연결(`06_star`), 유레카(`07_eureka`), 여정(`08_journey`) 8컷 캐릭터가 행동에 따라 살아 움직입니다.
   - `지식 포만감 · 기분 · 경험치` 바로 아래의 **작업 환경 상태창**이 현재 꽂힌 컴퓨터의 여유 RAM, CPU 코어, 외장하드 여유 공간과 주조 적합도 점수를 실시간 진단합니다.
2. **자율 마크다운 위키 정원사 (`wiki_gardener.py` + `vault/`)**
   - 메모나 분석 노트를 넣으면 YAML 메타데이터, 해시태그, 기존 기억과의 `[[양방향 시냅스 링크]]`를 자동 생성해 `.md` 파일로 영구 보존합니다.
3. **외부 모델 골격 해부대 & 독자 양자화 주조소 (`quant_forge.py` — `SynapseQuant`)**
   - **골격 해부대**: 외부 오픈모델(`Qwen 0.8B`, `Gemma 4 E2B`) 및 실제 `.gguf` 바이너리 헤더를 분해해 가져올 핵심 원리(GQA, SwiGLU, 블록 양자화)와 덜어낼 거대 다국어 군더더기를 분리합니다.
   - **직접 주조소**: 내 위키 어휘와 시냅스 공출현 행렬로 신경망 가중치를 학습한 뒤, **32개 단위 대칭 블록 스케일링(`FP16 scale`) + `INT4` 니블 패킹(1바이트에 4비트 가중치 2개 수납) / `INT8` 양자화**를 직접 수행하여 `models/*.sbrain` 파일을 생성하고 압축률(`~84% 절감`)과 코사인 정밀도를 계측합니다.

- **[완료] H단계 (`FIELD_SITES` · `field_profile()` · `POST /api/evo/field/sortie`)**: **⚔️ 근육 실전 투입** — 체육관에서 자란 4대 근육이 드디어 실제 기관에서 일합니다. 🧠 추론 → 성좌 원탁 담론에서 `2 + Lv÷4` hop 논증 체인을 엮고 그 깊이만큼 뉴런 증류 강도를 올림 · 📖 문맥 → 위키 기억 호출에서 학습된 가중치 6종(주어·서술·부정·단정·소유주·링크)으로 실제 노트를 재랭킹하고 신뢰 호출 매수를 2→6장으로 확장 · 💻 코딩 → 4단계 감사에서 학습된 4×4 버그 지문 행렬로 실제 코드의 의심 클래스를 순위화한 뒤 정적 진단 결과와 **정직하게 채점**(행렬이 영점이면 "🍼 아직 학습 전"으로 신고하여 우연한 argmax 적중을 가로채지 않음) · 🗂️ 정리 → 위키 시냅스 엮기에서 학습된 선반 임계값(`thr`)과 체육관 자신의 `_org_sim` 으로 실제 노트 쌍을 심사. 모든 출동은 **⚔️ 실전 보고서 원장**(최대 40건)에 남고, 심장박동은 3박마다 스스로 실전 출동을 나가 일지에 `kind: field` 로 기록합니다. 이를 위해 학습 역학도 정직하게 고쳤습니다 — 정답일 때도 updater를 호출해 근거를 쌓도록 하여(코딩 행렬 16/16 비지영점) "근거 없이 안다고 주장"하는 얼어붙은 영점 행렬을 없앴고, 기각된 돌파 가설은 **가중치까지 롤백**해 실험 잔여물이 두뇌에 남지 않게 했으며(209회 기각이 `w_sub=156.75` 를 몰래 쌓던 문제), 정리 근육의 성공 보강은 서랍 과잉 병합을 유발하므로 의도적 no-op으로 두었습니다. 4근육 전부 3티어 완주(추론 Lv32 · 문맥 Lv24 · 코딩 Lv20 · 정리 Lv24) 재검증 완료
- **[완료] I단계 (`record_experience()` · `experience_curriculum()` · `field_metrics()` · `GET /api/evo/experience`)**: **📓 실전 오답 노트 — 경험에서 배우는 두뇌** — 근육이 인공 퍼즐이 아니라 **자기 실전의 성공·실패**를 교재로 다시 배웁니다. 4대 실제 채점지: 💻 코딩 = 4단계 감사의 `top1_hit`(근육 예측 1순위 vs 정적 진단이 찾은 실제 결함 클래스) · 📖 문맥 = 실제 채팅의 `audit_chat_grounding` 등급(근육이 고른 1순위 기억이 정말 근거가 되었는가; `high` 는 교재로 쓰지 않고 **정직하게 skip**) · 🗂️ 정리 = 실제 vault 클러스터링의 과잉병합/누락 쌍 · 🧠 추론 = 실제 담론의 `gain_pts`(점수를 올린 사슬은 유효 체인으로, 내린 사슬은 중간 hop을 지우고 정답을 `unknown` 으로 가르쳐 억측을 막음). 훈련 세션은 오답 노트를 우선 복습하고 그 라운드 수와 맞힌 오답 수를 응답으로 돌려주며, 실전 채점지가 쌓인 근육일수록 세션의 더 많은 부분을 자기 경험에 씁니다. UI는 근육 카드의 얼굴을 **레벨 → 실전 적중률**로 바꾸고(레벨은 "숨은 시험 합격 도장"일 뿐이라는 설명과 함께), 📓 오답 노트 카드에 근육별 적중률 막대·복습 라운드·채점지 역사(✔ 맞힘 / ✘ 오답 / ♻️ 갱신됨)를 보여줍니다.
  - 이 과정에서 **학습 자체를 막던 구조적 결함 4개**를 고쳤습니다: ① `_solve_context`·`_context_features` 가 인공 문법에 하드코딩되어 실제 질문에서는 배울 수 없었음 → **캡처 시점에 특징을 동결**하는 `real_mode` 경로 신설(동일 퍼셉트론 `w += 0.3·(f_good − f_bad)`). ② `_solve_reasoning` 이 JSON 왕복 후 리스트 facts 를 `set()` 에 넣어 `TypeError: unhashable type: 'list'` → 튜플 정규화. ③ 정리 근육의 실전 교재가 **표현의 한계** 때문에 원리적으로 학습 불가 — 실제 카테고리는 복합어("Ghidra·역공학")라 체육관의 증거 검사 `cat in title` 이 항상 거짓이었고, 태그 유사도가 2개 태그 퍼즐에 맞춘 `/2.0` 상수라서 실제 노트는 태그 1개만 공유해도 0.5점(거의 만점)을 받아 엉뚱한 노트가 붙었음 → **단일 번역 함수** `real_org_note_view()`(제목에 실제 등장하는 카테고리 별칭 + 제목 머리의 문서 종류)와 실전 경로의 **자카드 정규화**로 교체. ④ 교재와 현장이 서로 다른 노트 표현을 써서 **배운 것이 행동으로 전이되지 않음** → 시냅스 엮기(현장)와 오답 노트(교재)가 같은 번역을 공유.
  - 정직성 장치: 오답 노트는 **상황(key)별 최신 1장**만 교재로 씁니다 — 살아있는 위키의 낡은 스냅샷을 계속 복습하면 서로 모순된 신호로 임계값이 진동하기 때문이에요. 대신 시도는 **누적 계수기**(`field_stats`)로 따로 세고, 갱신된 과거 시도도 화면에서 지우지 않고 `♻️ 이후 상황으로 갱신됨` 으로 표시합니다. "모든 쌍 정확"이라는 엄격 기준 뒤로 실제 진전이 가려지지 않도록 **연속 품질 점수**(정리 품질 %)를 함께 보고하고, 실전 vault에서는 고정 보폭 뱅뱅 제어(±0.075)가 과잉 조정이라 **감쇠 비례 제어**로 바꾸면서 과잉·누락 두 밸브를 모두 열었습니다(기존에는 `over >= under` 일 때만 브레이크가 잡혀 과잉병합 8쌍이 몇 라운드를 학습해도 그대로 남았습니다).
  - 검증: 오프라인에서 정리 근육이 **과잉 0·누락 0(품질 100%)으로 수렴**(진동 소멸), 코딩 0%→75%, 문맥 100% · 라이브 E2E 12단계 — fresh 🍼 → 자기 오답 3라운드 복습 → **동일 코드 재감사 🎯 `top1_hit`**, 실제 엮기 3회에서 오답 복습 정답 `0→2→3`, 최종 4근육 채점지 11장(추론 100% · 문맥 100% · 코딩 50% · 정리 25%/품질 98.5%) · 인공 커리큘럼 회귀 없음(4근육 3티어 완주, 정리 `thr=1.000`) · UI 렌더 검증 12항목 통과
