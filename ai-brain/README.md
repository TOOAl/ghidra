# 🧠 시냅스몽 · 외장하드 서식형 다마고치 AI 두뇌 (`ai-brain/`)

> **데이터센터 없이, 내 외장하드 안에서 자라나는 살아있는 나만의 양자화 AI 두뇌**  
> 외부 모델을 통째로 내려받아 빌려 쓰는 대신, **외부 모델의 골격 설계 원리만 해부해 참고하고 내 마크다운 위키 지식으로 직접 4비트·8비트 양자화 두뇌(`.sbrain`)를 주조**합니다.

---

## ✨ A단계 v2 핵심 구성

1. **8가지 감정·장면의 시냅스몽 & 작업 환경 상태창 (`web/assets/01~08`, `tamagotchi.py`, `host_probe.py`)**
   - 인사(`01_greet`), 호기심(`02_curious`), 소용돌이 흡수(`03_swirl`), 고민(`04_brainstorm`), 영감(`05_drop`), 별자리 연결(`06_star`), 유레카(`07_eureka`), 여정(`08_journey`) 8컷 캐릭터가 행동에 따라 살아 움직입니다.
   - `지식 포만감 · 기분 · 경험치` 바로 아래의 **작업 환경 상태창**이 현재 꽂힌 컴퓨터의 여유 RAM, CPU 코어, 외장하드 여유 공간과 주조 적합도 점수를 실시간 진단합니다.
2. **자율 마크다운 위키 정원사 (`wiki_gardener.py` + `vault/`)**
   - 메모나 분석 노트를 넣으면 YAML 메타데이터, 해시태그, 기존 기억과의 `[[양방향 시냅스 링크]]`를 자동 생성해 `.md` 파일로 영구 보존합니다.
3. **외부 모델 골격 해부대 & 독자 양자화 주조소 (`quant_forge.py` — `SynapseQuant`)**
   - **골격 해부대**: 외부 오픈모델(`Qwen 0.8B`, `Gemma 4 E2B`) 및 실제 `.gguf` 바이너리 헤더를 분해해 가져올 핵심 원리(GQA, SwiGLU, 블록 양자화)와 덜어낼 거대 다국어 군더더기를 분리합니다.
   - **직접 주조소**: 내 위키 어휘와 시냅스 공출현 행렬로 신경망 가중치를 학습한 뒤, **32개 단위 대칭 블록 스케일링(`FP16 scale`) + `INT4` 니블 패킹(1바이트에 4비트 가중치 2개 수납) / `INT8` 양자화**를 직접 수행하여 `models/*.sbrain` 파일을 생성하고 압축률(`~84% 절감`)과 코사인 정밀도를 계측합니다.

## 🗺️ A → B → C 통합 로드맵

- **[완료] A단계**: 포터블 시냅스몽 본체 + 마크다운 위키 정원사 + 외부 골격 해부 및 자체 `INT4/INT8` 양자화 두뇌 주조소 + 환각 진단·처방실
- **[완료] B단계 (`rl_gym.py`)**: 데이터센터 GPU 없이 숙주 CPU만으로 수백~수천 판 훈련하는 **5인 꼬마 뉴런 강화학습 체육관** + 가중치 병합 없는 **다수 심판 합의(`Poor Voters, Good Judges`)** + **선택지 확률 채점 및 75% 미만 주인님 코칭(`Human-in-the-Loop`)** + `rl_council_int8.sbrain` 양자화 정책 저장
- **[완료] B+ 무한 성좌 & 천재 심사원 (`genius_pantheon.py`, `genius_scout.py`)**: 영역별 천재 성좌 원탁 담론, 주인님 생각 입체 피드백, 동서양 50+ 인물 업적·강점·한계 검증 및 자유 성좌 배치·이동
- **[완료] C단계 (`self_evolving_forge.py`, `ghidra_scripts/SynapseDissectHeadless.py`)**: **4대 핵심 능력 × 5대 필수 기관 × 6단계 자가 진화 시냅스 공방** — `Ghidra 12.3` 헤드리스 브리지 & Binary X-Ray 분해 → 핵심 원리 설계도 번역 → 우리 식 파이썬 코딩 → 원인 역추적 돋보기 & 복어 독 제거기 → 타임머신 세이브 & 투명 유리방 쌍둥이 검증 → `.py` + `.sbrain` + `[[위키 기억]]` 영구 스킬 카트리지 장착
- **[완료] D단계 (`evolution_heartbeat.py`)**: **자가 진화 심장박동 💓** — 주인님이 자리를 비운 사이 두뇌가 2분마다 스스로 꿈 조각(니블 팩커·패리티 수호기·델타 압축기·데드존 양자화기·다수결 스무더·체크섬 파수꾼 6종)을 6단계 공방으로 혼자 진화시켜 영구 장착하고, 장착 후에는 약화된 버그를 심어 면역력을 검증하는 **예방접종 훈련**으로 전환. 모든 과정은 「주인님 없는 사이의 진화 일지」 UI와 박동 알림 토스트로 실시간 보고 + **💬 주인님 소원 속삭임 창**(`POST /api/evo/heartbeat/chat`): 소원 기록(다음 진화 박동이 그 소원을 품고 꿈꿈)·재우기·깨우기·즉시 박동·진화 보고 의도를 한국어 대화로 알아듣고 말풍선 대화창에 기록
- **[완료] E단계 (`core_ability_engine.py`)**: **핵심 능력 성장 체육관 🏋️** — 스킬 개수가 아닌 **4대 핵심 근육(🧠 추론 · 📖 문맥 이해 · 💻 코딩 · 🗂️ 정보 정리)** 을 자가 진화로 성장. 능력별 자기 커리큘럼(현재 난이도 연습 → 퍼셉트론/밴딧 가중치 업데이트 → 난이도+1 숨은 시험 ≥75% 합격 시 레벨업)과 레벨업 시 우리 식 `INT4 .sbrain` 능력 캡슐 냉동 보존. 심장박동 4박 중 3박이 자율 훈련(스킬 설치 없음, 순수 능력만 상승)에 쓰이며, 체육관 UI는 4축 레이더 차트·근육 카드·훈련 로그를 실시간 표시. **한계 돌파 연구 🚀**: 능력별 상한(예: 추론 Lv 16)에 닿으면 종료가 아니라 ① 현재 두뇌로 새 유형 벽을 응시(벽 계측) → ② 한계 진단·가설 수립(일지에 원문 기록) → ③ 가설 언락 후 자기 실험 → ④ 숨은 시험 ≥75% 시 상한 확장(16→24→32, 3티어), 실패 시 가설 기각·롤백 후 재도전. 최종 티어 상한 도달 시 위키 기억나무에 「열린 연구 과제」 노트를 심어 다음 세대 두뇌에게 바통을 넘김
- **[완료] G단계 (워크벤치 3종 · `POST /api/evo/trace-chat`)**: 3~6단계 공방을 주인님 손끝으로 — **🔍 원인 역추적 대화창**(기관③ 돋보기에게 "왜 깨졌어? / 몇 번째 줄이 범인? / 복어독 있어? / 어떻게 고쳐? / 원리 공식 알려줘 / 유리방 결과 어때?" 를 물으면 현재 편집창 코드의 실시간 진단을 대화로 답변) · **📎 첨부파일 업로드창**(`.py/.txt/.md` 는 3단계 편집창에 착륙 + 4단계 돋보기 자동 가동, `.elf/.exe/.bin` 은 1단계 X-Ray 해부 → 설계도 번역 → 이식 초안까지 원클릭 주행) · **🧩 「우리 뇌에 지금 이식 적용」 버튼**(편집창 코드를 유리방에 먼저 검증해 불합격 시 `400` 차단, 6/6 합격 시 `.py` + `.sbrain` + 위키 기억 2장으로 영구 합체)
- **[완료] H단계 (`FIELD_SITES` · `field_profile()` · `POST /api/evo/field/sortie`)**: **⚔️ 근육 실전 투입** — 체육관에서 자란 4대 근육이 드디어 실제 기관에서 일합니다. 🧠 추론 → 성좌 원탁 담론에서 `2 + Lv÷4` hop 논증 체인을 엮고 그 깊이만큼 뉴런 증류 강도를 올림 · 📖 문맥 → 위키 기억 호출에서 학습된 가중치 6종(주어·서술·부정·단정·소유주·링크)으로 실제 노트를 재랭킹하고 신뢰 호출 매수를 2→6장으로 확장 · 💻 코딩 → 4단계 감사에서 학습된 4×4 버그 지문 행렬로 실제 코드의 의심 클래스를 순위화한 뒤 정적 진단 결과와 **정직하게 채점**(행렬이 영점이면 "🍼 아직 학습 전"으로 신고하여 우연한 argmax 적중을 가로채지 않음) · 🗂️ 정리 → 위키 시냅스 엮기에서 학습된 선반 임계값(`thr`)과 체육관 자신의 `_org_sim` 으로 실제 노트 쌍을 심사. 모든 출동은 **⚔️ 실전 보고서 원장**(최대 40건)에 남고, 심장박동은 3박마다 스스로 실전 출동을 나가 일지에 `kind: field` 로 기록합니다. 이를 위해 학습 역학도 정직하게 고쳤습니다 — 정답일 때도 updater를 호출해 근거를 쌓도록 하여(코딩 행렬 16/16 비지영점) "근거 없이 안다고 주장"하는 얼어붙은 영점 행렬을 없앴고, 기각된 돌파 가설은 **가중치까지 롤백**해 실험 잔여물이 두뇌에 남지 않게 했으며(209회 기각이 `w_sub=156.75` 를 몰래 쌓던 문제), 정리 근육의 성공 보강은 서랍 과잉 병합을 유발하므로 의도적 no-op으로 두었습니다. 4근육 전부 3티어 완주(추론 Lv32 · 문맥 Lv24 · 코딩 Lv20 · 정리 Lv24) 재검증 완료
